# Copilot Instructions (AI Lint)

This repository is governed by **AI Lint** doctrine located at `.ai-lint/`.

Before generating or refactoring code:
- Consult `.ai-lint/PHILOSOPHY.md`
- Consult `.ai-lint/doctrine/languages/<language>.md`
- Avoid patterns listed in `.ai-lint/rejects/languages/<language>.md`

If a rejected pattern seems necessary, consult `.ai-lint/overrides/OVERRIDE-PROTOCOL.md`
and propose an explicit override (Override / Reason / Risk / Mitigation).

Prefer code that is idiomatic and debuggable over code that is merely correct.
